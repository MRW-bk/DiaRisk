**DiaRisk** est une application web développée avec **Dash (Python)** qui permet aux professionnels de santé d’évaluer le risque de diabète chez les patients à partir de données cliniques.

L’application utilise un modèle **CatBoost** entraîné pour prédire le niveau de risque (**élevé ou faible**) et fournit une **probabilité de risque** ainsi que des **considérations cliniques personnalisées**. Elle permet également de **générer des rapports au format PDF**.

DiaRisk dispose d’une interface **multilingue** en anglais, français et arabe, ainsi que de **thèmes clair et sombre**. Son interface est entièrement **réactive (responsive)** et s’adapte aux différentes tailles d’écran pour une utilisation sur **ordinateurs de bureau, tablettes et appareils mobiles**.
